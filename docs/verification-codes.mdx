---
title: Verification codes at checkout
description: What 3D Secure is, when a merchant asks for a one-time code, and where to find it.
---

Some merchants run an extra check when you pay, called 3D Secure (Visa Secure or Mastercard Identity Check). Many of these checks pass silently in the background. Sometimes the merchant asks you to confirm the payment with a one-time code.

## Where the code appears

The code is sent by the card issuer, not by the merchant. Where you see it depends on the card:

- On ZikCards cards that support 3D Secure, the code appears as a banner at the top of your dashboard, with a copy button, and in Telegram if you have connected it.
- With a bank card, it usually arrives by text message or in your banking app.

Not every card supports 3D Secure. If a merchant insists on the check and the card does not support it, the payment cannot be completed with that card.

## Tips

- **Have your dashboard open before you press Pay.** The code is valid for that one payment and for a short time only.
- **Never share the code.** ZikCards never asks you for it, and nobody else has a reason to. A message asking for a code is a scam.
- **If the code page times out,** start the payment again rather than retrying the old page, and use the new code.
